# Day 22 (2026-11-19) — cellar RLS: the cellar locks its own shelves

**Built** (1 feature, both kitchens, the Make-it-Right arc's first row):

- **Cellar RLS — per-request identity stamp + a non-owner app role + five row-level
  policies.** The cellar (Postgres) now enforces "see only your own rows" *itself*,
  independent of the app. The door (`auth.py`/`auth.ts`) stamps the verified `sub` into
  a per-request identity (`app_identity` contextvar / AsyncLocalStorage); the session
  opens with `set_config('app.current_user_id', …)` so every statement in that session
  carries the caller's badge. A new **`taskflow_app`** role — *not* superuser, *not* the
  table owner — is what the apps connect as, so RLS **binds** it (the owner, `postgres`,
  bypasses for `db-push`/init/admin — `ENABLE`, not `FORCE`). Five policies
  (`ws_isolation`, `wm_isolation`, `prj_isolation`, `iss_isolation`, `plan_isolation`)
  scope `workspaces` / `workspace_members` / `projects` / `issues` / `payment_plans` to
  the caller's memberships, with `SECURITY DEFINER` helpers (`is_member_of`,
  `is_owner_of`, `ws_of_issue`) so the inner reads bypass RLS and don't recurse.
- **The `__doorless__` sentinel** opens every shelf for the three callers that legitimately
  need the whole cellar: doorless dev, the Razorpay webhook (no badge), and the
  **create-bootstrap** (`save_workspace_with_owner`) — the workspace doesn't exist yet,
  so `is_member_of` is false and the `WITH CHECK` would reject both INSERTs; the sentinel
  opens them. Fail-closed: an unset identity is `NULL`, and `NULL` matches no policy → 0 rows.
- **`ON_ERROR_STOP on` is load-bearing** in `cellar.sql`: a plain `psql -f` swallows errors
  and exits 0, so compose would believe `cellar-setup` "succeeded" with **no** policies armed.
  With it, any failing statement aborts the script → non-zero exit → the apps never start
  against a half-locked cellar.

**The decision → ADR:** the per-request identity stamp + non-owner app role is a real
architectural choice (a new DB role, a new per-session stamp, a doorless sentinel) —
captured in **ADR-017**.

**Baselines:** both kitchens green (PY + TS suites pass) · the RLS cycle
(reserve → `set_config` → release) proven against a live Postgres (`ts/scratch/rls-cycle-test*.ts`).
